- **macOS Playwright modifiers (6c):** Ctrl-click does not open a new tab on macOS Chromium (Cmd does); use `modifiers: ["ControlOrMeta"]` and register `context.waitForEvent("page")` before the click.
- **Vacuous negative e2e assertions (6c):** `expect.poll` / `toHaveURL` return on the first matching sample, so "nothing happened" checks pass immediately (a `router.push` changes the URL only after the RSC fetch). Prove absence with in-page counters plus a real in-page wait, then assert once.
